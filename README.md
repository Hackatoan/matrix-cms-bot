# matrix-cms-bot

A Matrix bot that publishes blog posts and photos to a static site straight from a DM.

☕ **Support:** [Buy Me a Coffee](https://buymeacoffee.com/hackatoa)

## Overview

DM the bot text or images and it publishes them to a static site — a lightweight, chat-driven CMS.

## Features

- Publish blog posts and photos via Matrix DM
- Generates/updates a static site
- Simple, self-hosted workflow

## Tech Stack

Python · Matrix (matrix-nio)

## Development

```bash
pip install -r requirements.txt
# configure your homeserver + access token, then run the bot
python3 bot.py
```
